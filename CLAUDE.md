# Кеплер — памятка для Claude

Сайт с трассой искусственного спутника на 3D-глобусе и 2D-карте для Земли, Луны и Марса.
Живой сайт: https://vanyassia.github.io/kepler-orbit/ · репозиторий: `vanyassia/kepler-orbit` (ветка `main`).
Подробные договорённости и текущее состояние — в файлах памяти проекта; эта памятка — карта кода и порядок работы.

## Правила работы (обязательно)

- **Язык.** Всё общение — на русском, простыми словами, без жаргона. Комментарии в коде — тоже на русском.
- **После любой правки сразу коммит, пуш и выкладка на сайт — без вопросов.** Работа не закончена, пока правка не на живом сайте и сайт не открыт и не проверен в браузере.
- **Математическая модель окончательная — не менять.** Задача двух тел по листку «Трасса спутника»: константы, порядок шагов и формулы описаны в `docs/formulas.md`, контрольный пример МКС — `src/physics/__tests__/sheet.test.ts`. SGP4 удалён навсегда.
- **Не возвращать** убранное по просьбе пользователя: SGP4, зону радиовидимости, затухание трасс, контуры регионов, линию терминатора на карте, надпись «задача двух тел», схему элементов орбиты (дуги Ω, i, ω, ν) на глобусе. В описаниях не упоминать учебное заведение и учебник.
- **Только с явного согласия:** менять освещение тел (шейдеры в `src/views/globe3d/shaders.ts`), переписывать историю `main` (force-push). Принудительный пуш ветки `gh-pages` в `scripts/deploy.sh` — обычная выкладка.
- **Учётные данные** (пароли, токены, вход в GitHub) вводит только пользователь.
- **Честность:** что не проверено (Safari, настоящий телефон, жесты), говорить прямо.
- Пользователь смотрит сайт в основном **в Safari на MacBook и на телефоне**. Скриншоты и видео для проверки делать можно сколько угодно.

## Команды

```bash
npm run dev               # сервер разработки http://localhost:5173 (во встроенном браузере: preview_start с именем kepler-dev)
npx tsc -b                # проверка типов
npx vitest run            # все тесты (сейчас около 270)
npm run build             # сборка в dist/
npm run deploy            # сборка и выкладка на GitHub Pages (scripts/deploy.sh, ветка gh-pages)
npm run update:fallback   # свежий снимок элементов спутников Земли → public/data/fallback-gp.json
npm run update:orbiters   # свежие элементы спутников Луны и Марса из JPL Horizons → public/data/orbiters.json
npm run update:regions    # регионы Луны и Марса из справочника USGS
npm run fetch:textures    # скачать и пережать текстуры (нужна macOS: sips, cwebp)
```

## Порядок выкладки

Робот GitHub Actions (`.github/workflows/update-data.yml`) **каждый день в 06:17 МСК коммитит данные в `main`** и сам выкладывает сайт. Поэтому перед своим пушем всегда забирать его коммиты:

```bash
git fetch -q origin && git merge -q --ff-only origin/main
git add <файлы> && git commit -m "Что сделано, по-русски"   # последняя строка: Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
git -c credential.helper= -c credential.helper='!gh auth git-credential' push -q origin main
npm run deploy
```

Затем дождаться, пока сайт отдаёт новый `index-*.js` (тот же, что в `dist/index.html`), и открыть сам сайт: GitHub Pages кэширует файлы около 10 минут, встроенный браузер тоже — при проверке добавлять к адресу любой параметр (`?fresh=1`). Проверка файлов через curl не заменяет проверку страницы.

## Важные механизмы и уроки

- **Плавность.** Глобус рисует кадры по требованию (`frameloop="demand"`), на паузе видеокарта не работает. Панели глобуса и карты после первого открытия не закрываются, а только скрываются (`Workspace.tsx`): иначе каждый переход заново грузит снимки 8K.
- **Снимки в отдельном потоке.** Если поток не сработал, загрузка откатывается на обычную и пишет `console.warn` — откаты не замалчивать: так нашлась ошибка 404 из-за относительных адресов.
- **Карта на телефоне** подгоняется по высоте и ведёт спутник, пока пользователь сам её не тронул (`autoFitRef`). `zoom.transform` из d3 сам не ограничивает сдвиг краями — нужен `z.constrain()`.
- **Ползунок времени.** Ширина часов и кнопки «Сейчас» постоянная: иначе ползунок меняет длину при нажатии и время прыгает.
- **Встроенный браузер:** пускает только `localhost:5173` и сам сайт. Если окно Claude закрыто другим окном, он рисует один кадр в секунду — замеры плавности тогда недостоверны. Эмуляция телефона включается шириной меньше 768 px.
- **Safari для замеров:** собрать в папку сессии, отдать своим маленьким Node-сервером и открыть отдельным окном (`osascript … make new document`). Адреса вкладок пользователя не читать, закрывать только свои вкладки.
- Встроенный снимок элементов — средние элементы SGP4, подставленные в задачу двух тел как есть. Расхождение с реальным положением растёт со временем: это свойство модели, а не ошибка.
