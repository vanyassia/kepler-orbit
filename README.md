# Кеплер — трасса спутника в 2D и 3D

**Сайт:** https://vanyassia.github.io/kepler-orbit/

Учебный проект (МАИ). Веб-приложение показывает движение искусственного спутника Земли
на 3D-глобусе и на карте мира. Положение рассчитывается по начальным элементам орбиты
из каталога CelesTrak в модели **задачи двух тел**: Земля — шар, возмущения не учитываются.
Формулы и константы — по листку «Трасса спутника»: подспутниковая точка считается через
сферический треугольник (sin φ = sin u·sin i, ab = atan2(cos i·sin u, cos u), λ = λ_Ω + ab − ω_З·t).

## Возможности

- Поиск спутника по-русски, по названию из каталога (латиницей) или номеру NORAD.
- Быстрый выбор: 52 известных спутника по группам, из них 23 российских: Метеор-М, Ресурс-П, Канопус-В,
  Обзор-Р, Кондор-ФКА, Электро-Л, Арктика-М, ГЛОНАСС, Меридиан (орбита «Молния»), Экспресс, Ямал, Гонец,
  Скиф-Д, Спектр-Р. Там же МКС, Тяньгун, Хаббл, GPS, Starlink и исторические спутники.
- **3D-глобус**:
  - текстуры NASA до 16K, смена дня и ночи по реальному положению Солнца, огни городов, облака, атмосфера;
  - эллипс орбиты, трасса;
  - экватор, линия узлов, апсиды, направление на точку весеннего равноденствия ♈;
  - три режима камеры.
- **2D-карта**:
  - трасса на несколько витков (прошлое и будущее);
  - день и ночь с плавными сумерками, ночные огни;
  - подсолнечная точка;
  - Москва и Смоленск выделены, подписаны столицы;
  - масштаб и сдвиг.
- **Земля, Луна и Марс**: переключатель центрального тела в шапке. Глобусы и карты Луны и Марса,
  трассы их спутников (LRO, Чандраян-1 и -2, Danuri, ARTEMIS-P1 и -P2; MRO, TGO, Mars Odyssey, Mars Express,
  Hope, MAVEN, Mangalyaan, а также Фобос и Деймос)
  по элементам JPL Horizons; места посадок (советские — выделены). Модель та же — задача двух тел.
- **Свои спутники** Земли, Луны и Марса: кнопка «Свой спутник» в быстром выборе или в поиске.
  Орбита задаётся высотами перицентра и апоцентра и углами i, Ω, ω, M₀ (для Луны и Марса — от экватора
  тела); спутники сохраняются в браузере, их можно удалить.
- **Регионы Луны и Марса**: моря, равнины, земли, горы и крупные кратеры по справочнику USGS
  (названия IAU, 176 объектов, русские подписи) — подписи на карте и глобусе.
- **Витки разными цветами**: текущий — циан, +1, +2, +3 — свои оттенки, дальше — общий;
  начала витков (восходящие узлы) подписаны на карте и глобусе. Трасса горит в полную яркость
  по всему показанному окну, без затухания к концам.
- **Управление временем**:
  - пауза;
  - скорость от ×1 до ×5000;
  - ползунок ±24 ч с засечками начала витков;
  - возврат к «сейчас»;
  - клавиши ← → для шага по времени.
- **Боковая панель**:
  - элементы орбиты (a, e, i, Ω, ω, M₀, N, T, высоты перигея и апогея);
  - текущее положение (φ, λ, h, V, r, ϑ, u);
  - панель «Расчёт по шагам» — шаги листка (2, 4, 5.1–5.8) с живыми числами.
- **Работа без сети**: кэш браузера (2 ч), затем встроенный снимок элементов, затем ручной ввод TLE.
- Тёмная тема и адаптивная вёрстка (телефон, планшет, десктоп).

## Запуск

**Проще всего:** дважды щёлкните файл `Запустить Кеплер.command` в Finder. Он при первом запуске
установит зависимости, соберёт приложение и откроет его в браузере (http://localhost:4173).
Чтобы остановить приложение, закройте окно Терминала. Если macOS при первом запуске не даёт
открыть файл, щёлкните его правой кнопкой и выберите «Открыть».

Вручную (нужен Node.js 20+):

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm test           # юнит-тесты физики и загрузки данных
npm run build      # сборка в папку dist/
npm run preview    # просмотр сборки: http://localhost:4173
```

Ссылкой можно поделиться: адрес содержит выбранный спутник и вид, например `?sat=52145&view=3d`.

Служебные команды:

```bash
npm run deploy            # опубликовать сайт на GitHub Pages (ветка gh-pages)
npm run update:fallback   # обновить встроенный снимок элементов (public/data/fallback-gp.json)
npm run update:orbiters   # обновить элементы спутников Луны и Марса из JPL Horizons
npm run update:regions    # обновить регионы Луны и Марса из справочника USGS
npm run fetch:textures    # скачать и пережать текстуры (нужна macOS: утилита sips)
```

Текстура 16K (≈ 20 МБ) не хранится в git. Если её нет, режим «16K» в меню слоёв глобуса
остаётся на 8K. Восстановить её можно командой `npm run fetch:textures`.

## Устройство проекта

```
src/physics/   чистые функции модели (шаги листка «Трасса спутника»), юнит-тесты в __tests__
src/data/      CelesTrak (OMM JSON), разбор TLE, кэш, популярные спутники, города
src/state/     состояние приложения (zustand) и часы симуляции
src/views/     2D-карта (Canvas + d3-geo) и 3D-глобус (three.js, react-three-fiber)
src/ui/        верхняя панель, поиск, боковая панель, шкала времени, «Расчёт по шагам»
docs/          formulas.md — описание модели для пояснительной записки
```

Все формулы с выводом, обозначениями по учебнику Константинова и контрольными примерами
описаны в [docs/formulas.md](docs/formulas.md).

## Проверка модели

- **Юнит-тесты** (`npm test`, 204 теста):
  - контрольный пример МКС из листка «Трасса спутника»: T, a, h_п, h_а, JD, S, λ_Ω,
    подспутниковые точки при t = 0 и t = 30 мин;
  - контрольные примеры Vallado (уравнение Кеплера, переход к АГЭСК, звёздное время);
  - интегралы энергии и площадей;
  - геостационарная орбита, максимальная широта трассы, межвитковый сдвиг;
  - спутники Луны и Марса против JPL Horizons;
  - разбор TLE против JSON;
  - цепочка запасных источников данных.
- **Электро-Л №4** по расчёту стоит на 165,8° в. д. — это его штатная точка стояния.
- **Ограничение модели.** Задача двух тел не учитывает сжатие Земли и атмосферу, поэтому
  расчётная трасса со временем отходит от реальной (для МКС — сотни километров за сутки).
  Самые точные положения — вблизи эпохи элементов.

## Быстродействие

- **Кадры по содержанию.** На скорости ×1 глобус и карта рисуются, когда картинка заметно сдвинулась (около
  10 кадров в секунду), при ускорении времени — на каждый кадр экрана. На паузе видеокарта не работает.
- **Трасса** пересобирается при сдвиге окна на шаг сетки, в остальных кадрах в видеокарту уходит один отрезок.
- **Карта** складывается из готовых слоёв: снимок и линии перерисовываются только при смене вида.
- **Загрузка:** сначала лёгкий снимок 2K, подробные — когда камера долетела; карта и формулы — отдельными
  файлами по требованию; текстуры в WebP (SSIM к исходным JPEG не ниже 0,99), шрифты — только кириллица и латиница.
- **Сбои:** без WebGL или при устаревшей странице панель показывает сообщение и выход (открыть карту,
  обновить страницу), а не пустой экран; потерянный контекст WebGL восстанавливается сам.
