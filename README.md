# Кеплер — трасса спутника в 2D и 3D

**Сайт:** https://vanyassia.github.io/kepler-orbit/

Учебный проект (МАИ). Веб-приложение показывает движение искусственного спутника Земли
на 3D-глобусе и на карте мира. Положение рассчитывается по начальным элементам орбиты
из каталога CelesTrak в модели **задачи двух тел**: Земля — шар, возмущения не учитываются,
Модель SGP4 подключена только как эталон для сравнения.

## Возможности

- Поиск спутника по названию (латиницей, как в каталоге) или номеру NORAD, быстрый выбор 10 популярных:
  МКС, Хаббл, Тяньгун, Метеор-М №2-3, NOAA-19, Terra, Landsat 9, ГЛОНАСС, Меридиан-10 (орбита «Молния»),
  Электро-Л №4 (геостационарный).
- **3D-глобус**:
  - текстуры NASA до 16K, смена дня и ночи по реальному положению Солнца, огни городов, облака, атмосфера;
  - эллипс орбиты, трасса, зона радиовидимости;
  - экватор, линия узлов, апсиды, направление на точку весеннего равноденствия ♈;
  - три режима камеры.
- **2D-карта**:
  - трасса на несколько витков (прошлое и будущее);
  - терминатор с плавными сумерками и ночные огни;
  - круг радиовидимости, подсолнечная точка;
  - Москва и Смоленск выделены, подписаны столицы;
  - масштаб и сдвиг.
- **Витки разными цветами**: текущий — циан, +1, +2, +3 — свои оттенки, дальше — общий;
  начала витков (восходящие узлы) подписаны на карте и глобусе.
- **Эталонная модель SGP4** (satellite.js) для сравнения: розовая трасса и положение на карте и глобусе,
  панель с расхождением |Δr| (по радиусу, вдоль орбиты, поперёк плоскости) и график расхождения от эпохи.
- **Управление временем**:
  - пауза;
  - скорость от ×1 до ×5000;
  - ползунок ±24 ч с засечками начала витков;
  - возврат к «сейчас»;
  - клавиши ← → для шага по времени.
- **Боковая панель**:
  - элементы орбиты (a, e, i, Ω, ω, M₀, N, T, высоты перигея и апогея);
  - текущее положение (φ, λ, h, V, r, ϑ, u);
  - панель «Расчёт по шагам» — вся цепочка формул с живыми числами.
- **Работа без сети**: кэш браузера (2 ч), затем встроенный снимок элементов, затем ручной ввод TLE.
- Тёмная тема и адаптивная вёрстка (телефон, планшет, десктоп).

## Запуск

**Проще всего:** дважды щёлкните файл `Запустить Кеплер.command` в Finder. Он при первом запуске
установит зависимости, соберёт приложение и откроет его в браузере (http://localhost:4173).
Чтобы остановить приложение, закройте окно Терминала. Если macOS при первом запуске не даёт
открыть файл, щёлкните его правой кнопкой и выберите «Открыть».

Вручную (нужен Node.js 20+):

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm test           # юнит-тесты физики и загрузки данных
npm run build      # сборка в папку dist/
npm run preview    # просмотр сборки: http://localhost:4173
```

Ссылкой можно поделиться: адрес содержит выбранный спутник и вид, например `?sat=52145&view=3d`.

Служебные команды:

```bash
npm run deploy            # опубликовать сайт на GitHub Pages (ветка gh-pages)
npm run update:fallback   # обновить встроенный снимок элементов (public/data/fallback-gp.json)
npm run fetch:textures    # скачать и пережать текстуры (нужна macOS: утилита sips)
```

Текстура 16K (≈ 20 МБ) не хранится в git. Если её нет, режим «16K» в меню слоёв глобуса
остаётся на 8K. Восстановить её можно командой `npm run fetch:textures`.

## Устройство проекта

```
src/physics/   чистые функции модели: формулы (1)–(16), юнит-тесты в __tests__
src/data/      CelesTrak (OMM JSON), разбор TLE, кэш, популярные спутники, города
src/state/     состояние приложения (zustand) и часы симуляции
src/views/     2D-карта (Canvas + d3-geo) и 3D-глобус (three.js, react-three-fiber)
src/ui/        верхняя панель, поиск, боковая панель, шкала времени, «Расчёт по шагам»
docs/          formulas.md — описание модели для пояснительной записки
```

Все формулы с выводом, обозначениями по учебнику Константинова и контрольными примерами
описаны в [docs/formulas.md](docs/formulas.md).

## Проверка модели

- **Юнит-тесты** (`npm test`, 88 тестов):
  - контрольные примеры Vallado (уравнение Кеплера, переход к АГЭСК, звёздное время);
  - интегралы энергии и площадей;
  - геостационарная орбита, максимальная широта трассы, межвитковый сдвиг;
  - разбор TLE против JSON;
  - цепочка запасных источников данных.
- **Электро-Л №4** по расчёту стоит на 165,8° в. д. — это его штатная точка стояния.
- **МКС**: сравнение с независимым расчётом по SGP4 (сервис wheretheiss.at). Расхождение растёт со временем
  от эпохи элементов:

  | Время от эпохи | 0 ч | 3 ч | 6 ч | 24 ч |
  |---|---|---|---|---|
  | Расхождение | 11 км | 44 км | 63 км | ≈ 440 км |

  Основная причина — прецессия орбиты из-за сжатия Земли, которую задача двух тел не учитывает.
