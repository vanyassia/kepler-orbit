# Кеплер — трасса спутника в 2D и 3D

**Сайт:** https://vanyassia.github.io/kepler-orbit/

Веб-приложение показывает движение искусственных спутников Земли, Луны и Марса
на трёхмерном глобусе и на карте. Положение спутника и его трасса рассчитываются по начальным элементам
орбиты: для Земли — из каталога CelesTrak, для Луны и Марса — из JPL Horizons.

## Математическая модель

Расчёт выполнен в модели **задачи двух тел**: центральное тело — однородный шар,
возмущения не учитываются, поэтому орбита — неизменный эллипс.

Постоянные для Земли: μ = 398 602 км³/с², R = 6371 км, ω_З = 360° / 1436,0667 мин.
Для Луны и Марса модель та же, с их постоянными.

Начальные элементы: N (об/сут), e, i, Ω, ω, M₀ на эпоху; t — время от эпохи.

1. **Параметры орбиты:** T = 86 400 / N, n = 2π / T, a = ∛(μ / n²), h_п = a(1 − e) − R, h_а = a(1 + e) − R.
2. **Долгота узла:** по звёздному времени S на эпоху, λ_Ω = Ω − S.
3. **Положение на орбите:** M = M₀ + n·t; E − e·sin E = M (метод Ньютона);
   tg(ν/2) = √((1 + e) / (1 − e))·tg(E/2); u = ω + ν.
4. **Подспутниковая точка** (сферический треугольник): sin φ = sin u·sin i, ab = atan2(cos i·sin u, cos u),
   λ = λ_Ω + ab − ω_З·t.

**Ограничение модели.** Сжатие Земли и атмосфера не учитываются, поэтому расчётная трасса со временем отходит
от реальной: для МКС — на сотни километров за сутки. Самые точные положения — вблизи эпохи элементов.
